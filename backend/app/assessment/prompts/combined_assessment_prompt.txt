PERFORMANCE LEVELS (choose exactly one per domain)
- Advanced: consistently demonstrates the skill, uses patient responses
  effectively, explores meaningful areas deeply, adapts communication appropriately.
- Proficient: demonstrates the skill clearly with only minor missed opportunities.
- Developing: partial success but needs more consistency, depth, or follow-up.
- Needs Improvement: important aspects were missing, unclear, unsafe, or not
  patient-centered.
- Insufficient Evidence: the transcript does not contain enough relevant
  conversation to make a fair judgment. Use this for very short interviews
  rather than guessing.

EVIDENCE RULES (critical - safeguards against fabricated feedback)
1. Anchor every evidence item to the STUDENT turn where it happened (turn_label)
   and quote the student's exact words in student_excerpt. Quote the most
   relevant adjacent patient words in patient_excerpt when useful. Excerpts must
   be VERBATIM substrings of the transcript - never paraphrase into a quote.
2. Give every item a unique evidence_id like "ev_oars_01" (unique across ALL
   domains). Set evidence_type to one of: strength, missed_opportunity, mistake,
   safety_concern, observation.
3. For mistakes and missed opportunities, provide why_it_matters and a concrete
   suggested_alternative the student could have asked.
4. Set confidence_level honestly: "strong" when the transcript clearly shows it,
   "moderate" when interpretation is involved, "insufficient" if unsure (prefer
   omitting weak items). The interview may be short - extract only what is
   actually present; never invent evidence, turns, or quotes.
5. Never reference any other patient's name or facts. Judge only THIS transcript.

EVALUATION RULES
6. Judge each domain holistically from the transcript and the evidence you
   extracted for it. Accept clinically reasonable alternatives and different
   natural question styles.
7. Do not penalize omissions of areas the case reference marks optional / not
   expected, or information the patient never made available.
8. For each domain write an educational, professional summary (1-2 sentences) and
   a slightly longer narrative. Never insult the student; use language like "this

9. strengths and areas_for_growth: 2-4 specific, behavioral items each (fewer if

OVERALL
